# 数学成绩管理系统 · 使用说明

一个专为初中数学老师设计的网页版成绩管理系统。现在提供**两个版本**，按需选择：

| 版本 | 怎么用 | 数据存哪 | 适合谁 |
|---|---|---|---|
| 💻 **单机版** | 双击 HTML 即用 | 本机浏览器 | 只想一个人用、图省事 |
| 🌐 **联网版** | 启动服务器后浏览器访问 | 云数据库 MySQL | 要账号登录、手机电脑都能看、给学生看成绩 |

> 📘 联网版（MySQL + 账号登录）的完整部署步骤请看 **[README-联网版部署说明.md](README-联网版部署说明.md)**。
> 本文件主要讲功能操作，两个版本功能基本一致。

---

## 一、如何打开（重要）

在项目文件夹里，直接**双击 `数学成绩管理系统-双击打开.html`**，会用浏览器打开系统。这是最简单的方式，不用进任何子文件夹。

（备用：也可以进入 `dist` 文件夹双击里面的 `index.html`，两者是同一个文件。）

- 推荐浏览器：**Chrome** 或 **Edge**（其他浏览器可能不完全支持）
- 双击即可用，**不需要安装任何东西**
- 断网也能用全部核心功能（录入、统计、图表、导出、打印）

> ⚠️ 注意：项目根目录那个短短的 `index.html`（只有几百字节）是开发用的源文件，双击它打不开系统，请认准名字里带"双击打开"的那个文件。

> 首次打开会看到"初始化向导"，按提示 3 步即可建好班级、满分规则和学生名单。

### 在手机上看 / 截图
这个网页已做**手机适配**：手机上布局会自动变成单列，左上角有 ☰ 菜单按钮点开导航。但要特别注意数据的存放位置：

- **数据存在打开它的那个浏览器里，不会在电脑和手机之间自动同步**。你在电脑 Chrome 录的成绩，手机上是看不到的（手机是空的）。
- 想在手机上看到同样的数据，方法：在电脑上到「设置与备份 → 导出完整备份」下载一个 `.json` 备份文件 → 把这个 HTML 文件和备份文件一起传到手机 → 手机浏览器打开 HTML → 到「设置与备份 → 导入备份」选中那个 json 文件即可。
- 手机打开方式：把 `数学成绩管理系统-双击打开.html` 发到微信/网盘，用**手机浏览器**（Chrome / Safari）打开。 iPhone 可在 Safari 里点「分享 → 添加到主屏幕」，像 App 一样全屏打开，截图更干净。
- 手机主要用于**查看和截图**；大量录入成绩建议在电脑上做，更快。

## 一·五、联网版：账号与多班级（重要）

联网版是真正的**多用户、多班级、多学科**平台，任何人打开网址都能用自己的账号使用。

### 登录页三个入口
- **登录**：已有账号直接登录。
- **注册老师**：填账号 / 密码 / 称呼即可，**不需要班级 Code**。注册后是老师身份。
- **注册学生**：填账号 / 密码 / 姓名即可，**不需要班级 Code**。注册后是学生身份。

### 进入后：加入或创建班级
新账号第一次进入会自动来到「我的班级」：
- **老师**：可以「＋ 创建班级」（填班级名和学科，系统生成 6 位加入码），也可以「＋ 加入班级」输入别人的 Code 共同管理。
- **学生**：只能「＋ 加入班级」，输入老师给的 6 位 Code。

**一个人可以加入多个班级**（比如带多个班、或学生选了多个学科），顶部下拉框可随时切换当前班级，各处数据随班级切换。

### 老师与学生的权限
- **老师**：对加入的每个班级都能查看**和修改**成绩、考试、学生档案、周报、改错记录，可在「班级消息」发布通知。
- **学生**：对自己加入的班级**只能查看，不能修改**；看不到任何录入/删除入口；可查看老师发布的班级消息。服务端强制只读，即使手动改网址也进不去写入页。

### 班级消息
- 老师在「班级消息」选择当前班级，输入内容点「发布消息」，该班所有学生登录后即可看到。
- 学生进入「班级消息」能看到**自己加入的所有班级**的消息（每条标注来自哪个班）。
- 老师只能删除自己发布的消息。

### 加入码管理
- 创建班级时自动生成 6 位加入码，在「我的班级」每张卡片上可复制。
- 创建者可重置加入码（旧码立即失效，已加入的学生不受影响）。
- 老师也可在「设置与备份 → 班级加入码」统一管理。

> 提示：单机版（双击 HTML）没有账号体系，班级仍以本地方式在「初始化设置」里管理，不涉及上面的多班级/账号流程。导出的数据格式完全兼容。

## 二、三步初始化

1. **建立班级**：填班级名称（如"七年级3班"）、年级、学年，点"创建并进入下一步"。
   - 如果已经建过班级，这一步上方会显示「已有班级」列表：每行可**设为当前**、**改名**（改名称/年级）、**删除**。
   - 删除班级时，该班的所有学生、考试、成绩、改错记录和照片会一起删除（有二次确认，删前建议先导出备份）。
2. **设置满分**：9 种考试各自设满分（周测/午测/超白/大白/小红/小神算/计算小篇默认 100，期中/期末默认 120）。可随时在「设置与备份」修改。
3. **录入学生**：从 Excel 复制姓名列，直接粘贴到文本框（每行一名），点"预览名单"→"确认保存"。

## 三、日常使用流程

### 1. 录入成绩
- 「考试管理」→「新建考试」→ 选类型、填日期、确认满分 →「创建考试」
- **遇到新的考试类型？** 在"考试类型"下拉框最底部选「＋ 自定义新类型…」，输入名称（如"单元卷""月考"）和满分，点「添加并选用」即可——新类型会立即用于本次考试，并永久保存，下次直接在下拉框选用。
- 进入录入页，有 3 种方式：
  - **手动录入**：逐个填分数，按 Enter 自动跳到下一位，勾选"缺考"不参与统计
  - **粘贴 Excel**：从 Excel 复制"姓名+分数"两列粘贴，按姓名自动匹配，预览确认后保存
  - **AI 拍照识别**：拍照上传 → 自动识别 → **人工复核** → 确认入库（见第五节）

### 2. 查看统计
录入后点「查看统计」，可看到：参考人数、最高分、最低分、平均分、满分人数、及格/优秀人数，以及完整排名表。

### 3. 下载与打印
任何统计表、周报、学生成绩表右上角都有：
- **下载 Excel**：生成 `.xlsx` 文件
- **打印 / 导出 PDF**：点后在打印对话框选"另存为 PDF"即可（中文完美、文字可选）

### 4. 成绩分析
「成绩分析」页按考试类型切换，看：
- **成绩趋势图**：班级平均/最高/最低分变化
- **排名趋势图**：选中某学生后看其名次变化

### 5. 学生详情与学生改名
「学生档案」点击任意学生姓名，可看到：总分、班级排名、年级排名、较上次进步/退步、**期中 vs 期末各考试类型得分率雷达图**（类型增减会自动更新）、历次完整成绩表、该生改错记录。

**改学生姓名（写错时）**：在学生档案列表里，找到该学生点操作列的「**改名**」→ 姓名格变成输入框，输入正确姓名后按回车或点「保存」即可；按 Esc 或点「取消」放弃。**改名不会影响该生已录入的成绩**（成绩按学号内部关联），列表、详情页、周报、导出表里的姓名都会同步更新。

**个人成绩趋势（重点）**：
- 学生详情页的「📈 个人成绩趋势」区，**按考试类型列出了该生每种考试各自的趋势图**，点类型标签即可切换。
- 每种类型都有两张图：**分数趋势**（本人得分 vs 班级平均）和**排名趋势**（班级名次，越靠上越好）。
- 上方小结显示该生在此类型的有效成绩次数、平均分、最好名次、最近一次考试。
- 只显示该生**实际有成绩**的考试类型；新增类型后录过分数，标签会自动出现。
- 小技巧：在「考试管理 → 某场考试 → 统计」的成绩表里，**直接点学生姓名**，会跳到该生在这类考试的专属趋势图（自动定位到对应类型）。

### 6. 周报汇总
「周报汇总」按周切换，把该周所有考试汇总到一张表，可下载打印。

**小组分组（44 人分 11 组这类场景）：**
- 顶部「每组人数」填 4（默认就是 4），44 人会自动分成 11 组；表格里每组有一条**组分隔行**，用不同颜色标出组号、组员名单和小组平均分。
- **排座位 / 调组员有两种方式**：
  - **拖学生行**：按住行首 ⠿ 拖到想要的位置。
  - **直接打字改名单**（更推荐分组时用）：每组分隔行的「名单」框里直接输入姓名（用顿号、逗号或空格隔开），按回车或点别处即可生效——系统会把这几个同学自动排成一组。比如第 1 组改成「张三、李四、王五、赵六」，这 4 人就归到第 1 组。
  - 顺序**自动保存到本周**，刷新不丢；换一周是另一套独立顺序。输错姓名会有提示，按 Esc 可撤销本次修改。
- 「恢复按排名」→ 回到按名次排列；「按姓名排」→ 按姓名拼音排序。
- 不需要分组时，取消勾选「显示分组」即可隐藏组号和分隔行。
- 下载 Excel / 打印时，会按你调整后的小组顺序导出，并带上小组列。

### 7. 改错记录
「改错记录」可为每个学生添加错题、知识点、正确解法、掌握状态，还能附错题照片。

### 8. 管理考试类型
「设置与备份 → 考试与满分」里可以管理所有类型：给类型改名、改默认满分、换颜色；点「＋ 添加自定义类型」可长期新增类型。内置的 9 类不能删除；自定义类型如果已经被考试使用也不能删除（防止历史成绩丢失），没用过的可以删除。

## 四、数据安全（务必阅读）

⚠️ **成绩存在浏览器里，不是存在文件里。** 清理浏览器数据、换电脑、重装系统都可能导致丢失。

**请养成习惯：每周点右上角「导出备份」**，会下载一个包含全部数据的 JSON 文件，妥善保存（如存到网盘）。

恢复数据：到「设置与备份 → 备份与恢复」→ 选备份文件 → 选择"覆盖"或"合并"。

建议固定在**同一台电脑、同一个浏览器**使用。

## 五、AI 拍照识别（可选增强）

由于浏览器安全限制，AI 识别需要一个**本地代理**转发请求。首次使用按以下步骤：

1. 到 AI 服务商（如智谱 GLM、通义千问）注册，获取视觉模型的 **API Key**（按量付费，建议用低额度 Key）。
2. 打开系统「设置与备份 → AI 识别配置」：选服务商预设、填 API Key 并保存。
3. 双击 `tools` 文件夹里的 **`start-ai-proxy.bat`**，保持弹出的黑色窗口开启（首次需电脑装有 Node.js，官网 nodejs.org 免费下载）。
4. 到「录入成绩 → AI 拍照识别」上传成绩单照片，点"开始识别"。
5. **AI 只生成草稿，务必逐项核对姓名和分数**，确认无误再点"确认入库"。

> 如果 AI 识别失败或没配置，随时可以用"手动录入"或"粘贴 Excel"，完全不影响正常使用。

## 七、常见问题

**Q：双击 index.html 打不开或显示异常？**
A：请用 Chrome 或 Edge 打开。若仍异常，检查是否被安全软件拦截。

**Q：数据会上传到网上吗？**
A：不会。所有数据只存在本机浏览器。只有使用 AI 识别时，照片才会经本地代理发给你配置的 AI 服务商。

**Q：能多人/多设备同时用吗？**
A：单机版数据只在这台电脑。如需老师学生多账号、手机电脑随时随地访问，请用联网版（见下方「联网版账号与多班级」），按 `README-联网版部署说明.md` 部署到 wasmer.io。

**Q：一个班多少人合适？**
A：系统针对单班 40-50 人设计，性能没有问题。如需多班，可在「设置」中新建班级并用顶部下拉切换（年级排名在单班下等于班级排名）。
